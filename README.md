# WordBook 1.6

常驻 Windows 的中英文翻译记录助手。浮窗保留输入框、输出框和“设置”按钮；输入框右下角提供翻译方向选择。右下角托盘和屏幕边缘图块提供入口，任务栏不显示程序图标。

## 启动

双击 `dist\WordBook\WordBook.exe`，保留整个文件夹。程序已包含 Python 和 Qt。重复双击会唤起已有实例，不会再开一个 WordBook。

首次运行显示本机保存、主动发送文本和 API 可能收费的说明。默认在右边缘显示小图块，悬停约 200 毫秒展开。拖动顶部小把手可吸附到左、右或上边缘。托盘提供展开、收起、固定展开、词库、设置、退出；关闭窗口只收起。

通过全局快捷键唤起后，若用户没有操作浮窗，内容会保留 5 秒再恢复小图块；一旦鼠标进入、点击、按键、滚轮或拖放，立即回到常规收起逻辑。常规状态下，鼠标离开面板约 600 毫秒后自动恢复小图块。输入框保留焦点或查看详细解析不会持续固定窗口；后台翻译完成也不会把已收起的窗口重新展开。输入框有尚未提交的编辑且仍在编辑、拖动中、菜单/对话框打开或托盘选择“固定展开”时暂缓收起；操作结束后继续检查。收起不会丢失草稿，托盘“收起”可手动立即收起。

## 输入与翻译

- 输入框右下角每次启动默认显示 **英译中 ⌃**，点击可选择英译中或中译英。当前只提供中文和英文，切换方向不发起翻译请求。
- 选择 **中译英** 后，该次翻译成功完成时会自动切回 **英译中**。失败、超时、缺少密钥或仍待翻译时保留中译英，方便再次按 Enter 重试。
- 输入或粘贴文本后，按 **Enter** 翻译并记录；**Shift+Enter** 换行。
- 复制新英文后按全局快捷键，读取当前纯文本剪贴板并提交。剪贴板未变化时，只展开最近提交的记录，手动输入的新记录也会正确显示。
- 在其它程序里用鼠标拖选或双击选中文字后，按鼠标侧键也能直接读取并提交，详见下节。
- 刚在设置里保存密钥或快捷键后，已有剪贴板内容不会被当作新复制内容自动提交；需再次复制英文。
- 纯文本可拖入图块或面板；文件和其他内容会被拒绝并提示。
- 空内容不能提交，最多 1000 个字符；单词或句子/短语自动识别。

每次主动提交都先在本机保存原文，再后台请求翻译。同一翻译方向下，重复文本忽略首尾空白、连续空白和英文大小写，合并卡片并累计遇到次数。不同方向独立保存，因此不会把英译中的旧译文用作中译英结果。已有解析默认复用；单纯唤起窗口不新增遇到事件，也不调用 API。打开旧卡片时会显示该记录自己的方向；重新提交并成功后仍按“中译英完成即回到英译中”的规则处理。

未填写密钥或网络失败时，原文保留为“待翻译”。填好密钥或恢复网络后，可以再次按 Enter 主动提交。程序没有独立的重试/重新解析按钮，不会在超时后自动重复收费请求。

默认卡片只显示原文、完整直译和遇到信息，不写语法、语境或“这是……”之类的说明。点击输出内“详细解析”才显示详细义项、用法补充及“AI 生成”例句，不追加请求。

单词默认依次显示 **美式、英式 IPA 音标、词性和直译**，例如 `tomato` 的美式 `/təˈmeɪtoʊ/`、英式 `/təˈmɑːtəʊ/`，以及 `n. 番茄`。音标和译文通过同一次翻译获取，自动保存，重启后仍可查看；句子/短语只显示完整直译，不显示整句音标或词性。

旧词条没有音标时，仍保留原译文并提示补全。再次在输入框按 Enter，才会请求补全两种音标，可能产生 API 费用；原有译文与笔记保持。补全失败保留旧内容，不自动重试；补全成功后重复提交沿用缓存。音标由 AI 生成，可能有误。

## 鼠标侧键划词

默认两个鼠标侧键都可划词。请在其它程序中先用鼠标拖选一段文字，或双击、三击选中内容，然后按侧键：

1. 程序只在确认鼠标刚完成选择后才接管侧键；读取成功后展开浮窗，把原文保存到本机，并在后台按当前翻译方向请求翻译。
2. 读取时会在本机模拟一次 `Ctrl+C`，因此剪贴板会变成所选文字，和手动复制一样；程序不会监听或上传其它剪贴板变化。
3. 没有选区时不会误提交，侧键继续执行浏览器或资源管理器原本的后退/前进功能。WordBook 自己是前台窗口时也不触发。
4. 可到“设置 → 鼠标侧键划词”选择关闭、仅侧键 1、仅侧键 2 或两个侧键。用键盘 `Shift+方向键` 做出的选区不在首版侧键支持范围内。
5. 空选区、复制失败、超过 1000 个字符、无密钥或网络失败都会显示原因；原文先保存，失败后可再次按 Enter 主动提交。

部分以管理员权限运行、禁止复制或受保护的应用可能拒绝读取选区，此时会明确提示，不会假装翻译成功。

## 一个按钮里的六项操作

鼠标悬停在浮窗的“设置”按钮上，展开：

1. 修改：编辑当前已翻译卡片的译文与说明。
2. 删除：确认后删除当前卡片及其遇到记录。
3. 词库：搜索原文或译文，按“全部翻译类型、英译中、中译英”筛选，双击打开旧记录。可按住 Ctrl 多选后“删除选中”，也可导出当前列表。
4. 设置：填写密钥、调整模型和快捷键、管理开机启动、备份恢复。
5. 7 天导出。
6. 30 天导出。

当前版本移除了复习界面和提示；已有词库及历史数据保留，不会因更新清空。

## DeepSeek 密钥、费用和隐私

在 [DeepSeek 控制台](https://platform.deepseek.com) 创建自己的 API 密钥，再在 WordBook 设置页输入并保存。不要把密钥发到聊天中。输入框可显示/隐藏本次输入，不回显已保存的完整密钥。

密钥仅存入 Windows 凭据管理器，不放入配置、SQLite、备份或日志；安全存储不可用时明确报错，不回退为明文保存。默认模型 `deepseek-flash` 可修改。设置页“测试连接”发送固定测试文本，操作前会确认可能收费。

只有通过快捷键、鼠标侧键划词、拖入或输入框主动提交的文字才发送至 DeepSeek。程序不监听并上传每次剪贴板变化。API 可能按 token 收费，价格以 [官方价格页](https://api-docs.deepseek.com/quick_start/pricing/) 为准；AI 解析与例句可能出错，应自行核对。

默认快捷键为 `Ctrl+Alt+W`。遇到占用会明确提示，在设置中可改为可用组合，例如 `Ctrl+Alt+9`；已保存的个人配置在更新后保留。

## 导出、备份和数据位置

最近 7/30 天指包含今天在内的连续本地日历日，按每次遇到的事件筛选。因此旧词今天再次遇到也会导出；导出为 UTF-8 Markdown，待翻译项明确标注。

导出文件只有 **原文、次数、翻译** 三列。词库“导出当前列表”使用累计次数；最近 7/30 天使用该时段的遇到次数。词库的翻译方向与搜索筛选会应用到导出；未得到译文时，翻译列写“待翻译”。

设置页可备份全部数据为 `.wbak`，建议保存到其他磁盘。恢复会替换当前词库，执行前确认，并先自动保存当前快照；密钥不会被备份或恢复。每天首次运行生成一份自动备份，保留最近 7 份。

数据通常在 `%LOCALAPPDATA%\WordBook\WordBook`，以设置页“打开数据目录”为准：

- `wordbook.sqlite3`：词条及事件；时间以 UTC 保存，界面和导出转为本地日期。
- `settings.json`：模型、快捷键、位置等，不含密钥。
- `自动备份\` 和 `恢复前快照-*.wbak`：备份。
- `wordbook.lock`：运行时单实例锁，退出自动释放；无需手动删除。

新版首次打开旧词库时自动升级，原有词条归入英译中，保留 ID、译文、次数和事件。旧版 `.wbak` 仍可恢复到新版；新版备份需用新版程序恢复。

打包程序默认登记当前用户的登录启动项，设置中可关闭。请把整个程序文件夹放在稳定位置；移动后从新位置启动一次。源码和隔离测试模式不登记启动项。

## 开发与验证

最终构建使用项目独立 `.venv310`（Python 3.10）。在项目目录运行：

```powershell
.\.venv310\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv310\Scripts\python.exe main.py
.\.venv310\Scripts\python.exe -m pytest -q -p no:cacheprovider --basetemp .tmp\pytest-run
.\build.ps1
```

本机系统临时目录可能没有读取权限，因此测试命令显式使用项目内的 `.tmp`；不需要删除或修改系统临时目录。

`requirements.txt` 是直接依赖约束，`requirements-lock.txt` 是验证环境版本。构建脚本隔离 DLL 搜索路径，并审查原生依赖来源，避免混入其他工具的运行库。输出 PyInstaller 文件夹式 Windows 程序。

GUI 回归测试必须使用新的隔离目录，不读真实 API 密钥，也不发真实请求：

```powershell
$env:WORDBOOK_TEST_DATA_DIR = "$PWD\evidence\new-gui-check"
Start-Process .\dist\WordBook\WordBook.exe -ArgumentList --smoke-first -Wait
Start-Process .\dist\WordBook\WordBook.exe -ArgumentList --smoke-reopen -Wait
```

已验证内容、截图、未实测场景和真实 API 调用边界见 [验收报告](验收报告.md)。
